Python jest językiem TYPOWANYM DYNAMICZNIE.
Oznacza to, że podczas przypisywania WARTOŚCI do ZMIENNEJ nie musimy deklarować TYPU DANYCH (Python sam zarządzi miejscem w pamięci).
Pod jedną zmienną możemy podstawiać różne typy danych.

liczba = 4
liczba = 'cztery'

FUNKCJE WBUDOWANE:
    -> print() – Wyświetl zawartości w konsoli. WARTOŚCI zostaną wyświetlone w jednym wierszu, jeśli zostaną oddzielone przecinkami.

    -> type() – Sprawdź typ zmiennej.
    -> isinstance(value, class) - Sprawdza czy dana WARTOŚĆ jest danego typu (klasy), np. insinstance(number, int) -> zwraca bool (True lub False)

    -> input() – Pobierz WARTOŚĆ od użytkownika z konsoli. Zawsze zwraca STRING, dlatego czasem trzeba dokonać konwersji na "int" lub "float".
            To co wpisze użytkownik jako "input", zostanie przypisane do WARTOŚCI, a następnie np. może zostać wyświetlone za pomocą funkcji "print".
            Docelowo nie będziemy używali tej funkcji. Dane będziemy pobierali z innych źródeł, np. źródłem może być interface.
    -> len(iterable) – Zwraca długość obiektu ITEROWALNEGO (czyli takiego, z których da się wyodrębnić konkretny element lub kilka elementów).
            Obiektami iterowalnymi są: STRINGI, LISTY, TUPLE, ZBIORY i SŁOWNIKI.
    -> round(number) – Zaokrągla domyślnie do jedności, ale też pozwala zaokrąglić do X miejsc o przecinku.
            round(number, precision) – Zaokrąglenie number (liczby zmiennoprzeciwkowej) do precision (dokładność) liczby po przecinku
            -> number – Argument pozycyjny. Potrzebny, aby podana funkcja zadziałała.
            -> precision – Argument opcjonalny. Ma wartość domyślną, można, ale nie trzeba go podawać, np: round(number, 2) – zaokrągli do 2 miejsc o przecinku.

    -> sorted(collection) -> sortuje obiekt KOLEKCJI -> zawsze zwraca LISTĘ (w kolejności wg. ASCI)
            sorted(iterable, /.., *.., key=none, reverse=False) # W argumencie "key" wpisujemy jakiej FUNKCJI chcemy użyć, żeby posortować.
    -> reversed(collection) -> sortuje obiekt KOLEKCJI w odwrotnej kolejności -> zawsze zwraca LISTĘ
    -> min(sequence) -> zwraca najmniejsza wartość z KOLEKCJI
    -> max(sequence) -> zwraca największą wartość z KOLEKCJI

    -> str(a) – Zamiana na typ danych NAPIS/CIĄG ZNAKÓW (str)
    -> int(a) – Zamiana na typ danych LICZBA CAŁKOWITA (int)
            Jeśli chcesz zamienić NAPIS (str) na LICZBĘ (int/float), to musi się on składać wyłącznie z CYFR. W innym wypadku wyświetli się błąd.
    -> float(a) - Zamiana wartości na LICZBĘ ZMIENNOPRZECINKOWĄ (float)
            Jeśli chcesz zamienić NAPIS (str) na float, to musi się on składać wyłącznie z CYFR lub może zawierać KROPKĘ (jest separatorem dziesiętnym)
            np. ze str = '123.12' można przejść na int za pośrednictwem float – Konwersja: str -> float -> int
    -> bool() – Konwersja danych na TYP LOGICZNY

    -> id() – Zwraca unikalny, całkowitoliczbowy identyfikator obiektu. W praktyce jest to adres tego obiektu w pamięci komputera.
            Każdy obiekt ma przypisane własne id w momencie jego tworzenia (id jest swego rodzaju "pseudo" liczbą/pozycją).
            w praktyce, używamy jej jedynie do sprawdzenia, czy coś jest HASHOWALNE.

    -> pow(a, b) – Potęgowanie a do potęgi b – NIE UŻYWAMY, ponieważ mamy operator **.

TYPY DANYCH W PYTHONIE:
    -> Numeryczne (typy proste)
        -> Integers (int): LICZBA całkowita, np. 2 lub -2. Liczby całkowite mogą być dowolnie duże (lub małe) i mogą przyjmować wartości ujemne.
        -> Floats (float): LICZBA zmiennoprzecinkowa (z ułamkiem), np. 2.5.

    -> Teksty (typ prosty)
        - Strings (str): TEKST, zawsze zapisywane w cudzysłowie (pojedynczym lub podwójnym), np. "Dwa" lub '2.5'.
        Każda treść umieszczona w cudzysłowie jest traktowana jako TEKST/STRING.

            -> METODY stringów (nie mylić z FUNKCJAMI numerycznymi) – metoda jest wywoływana na konkretnym obiekcie/instancji
                Dla "int" nie ma takich METODY – wyświetli błąd
            – Najczęściej wykorzystywane METODY stringów to:
                .split(',') – zwraca listę str / .strip() – usuń białe znaki / .lstrip() / .rstrip() /
                .replace('a', 'b') / '.'.join() / .startswith() / .endswith()
                .upper() / .lower() / .title() / .capitalize() / .isaplha() / .isdigit() / isnumeric() – ½ + 三
            – Żadziej wykorzystywane: strip() /
                .find() – zwraca index / .index() – zwraca index lub BŁĄD / .count() – zwraca liczbę wystąpień /

    -> Wartości logiczne (typy proste)
        – Booleans (bool): Wartości logiczne, czyli prawda (True) lub fałsz (False). Muszą zaczynać się wielką literą

    -> Struktury Danych (typ złożony) i ich METODY
        – Listy [list]: list[0] / list[0:3] / list.index('Aga') / list.remove('Aga') / list.append('Aga') / list.insert(0, 'Aga') / list[0] = 'Ewa'
            for element in list:

        – Krotki (tuple): tuple[0] / tuple[0:3] / tuple.index('Aga')
            for element in tuple:

        – Zbiory {set}: set.remove('Aga') / set.add('Aga') /
            (s1 - s3) – odejmowanie ZBIORU od ZBIORU / (s1 & s3) – część wspólna / (s1 ^ s3) – część rozłączna
            Nie możesz modyfikować elementu, ale możesz najpierw usunąć, a później dodać nowy.

        – Słowniki [dict]: dict.get('name') – wyświetl ELEMENT słownika / dict.pop('name')  – usuwanie / dict.get('name')
            dict['name'] = 'Aga' – dodawanie i edycja (dodajac istniejący klucz edytuje wartość)
            Iteracja: for key in dict.keys(): / for value in dict.values() / for key, value in dict.items():
                            print(key)              print(value)                print(f' Klucz: {key} + Wartość: {value}'))

    -> None – Posiada swój własny, unikalny typ o nazwie "NoneType". Jest on oddzielony od LICZB, TEKSTÓW i WARTOŚCI LOGICZNYCH.
